# 🕷️ 爬虫与数据采集模块

独立的数据采集模块，与 stock_monitor 解耦。各模块互相独立，可单独运行。

> **历史沿革**：原先集中在 `apps/crawlers/` 下（xueqiu / eastmoney / iptv / news 混放），
> 现已**拆平**到 `apps/` 下，`apps/crawlers/` 目录已删除。
> 旧的雪球 Selenium + DOM 解析版（`apps/xueqiu/`）也已删除，只保留接口版 `apps/xueqiu_api/`。
>
> 各轮代码整理的开发记录见 `docs/dev/爬虫模块-整理记录.md`（**不提交**）。

## ⚙️ 共享配置

统一配置在 **`apps/config.ini`**，由 `apps/config.py`（Python）读取；
Shell wrapper 脚本（`run_xueqiu.sh` / `run_eastmoney.sh` / `run.sh`）用内置的
`get_ini_value` 直接读同一个 ini（原 `apps/config.sh` 已删除）。

爬虫相关配置段按模块拆分（原 `[crawlers]` 段已取消）：

```ini
[xueqiu]
dir = /root/apps/xueqiu_api
data_dir = /data/xueqiu_data

[eastmoney]
dir = /root/apps/eastmoney
data_dir = /data/analyst_data

[iptv]
dir = /root/apps/iptv
data_dir = /data/iptv

[news]
dir = /root/apps/news
data_dir = /data/news
```

**路径解析规则**（`apps/config.py`）：ini 里写的是「容器内视角」绝对路径。

- 容器 / Linux 生产：原样使用（`/data` 是数据卷挂载点）
- Windows 本机开发：按 `[mount_point]` 映射到项目内
  （`/data` → `<项目根>/run`、`/var/log` → `<项目根>/logs`、`/root/apps` → `<项目根>/apps`）

```ini
[mount_point]
; 值以 / 或盘符开头 → 本机绝对路径；否则 → 相对项目根；前缀最长优先
/data              = run
/var/log           = logs
/root/apps/stockdb = E:/work/code/stockdb
/root/apps         = apps
```

支持 `${key}` 变量展开（引用同一段内的键），如 `[stockdb] pybao_dir = ${dir}/pybao`。

对应环境变量覆盖（`apps/config.py::get_path` 自动映射）：

| 配置项 | 环境变量 |
|---|---|
| `[xueqiu] dir` | `STOCK_MONITOR_XUEQIU_DIR` |
| `[xueqiu] data_dir` | `STOCK_MONITOR_XUEQIU_DATA_DIR` |
| `[eastmoney] dir` | `STOCK_MONITOR_EASTMONEY_DIR` |
| `[eastmoney] data_dir` | `STOCK_MONITOR_EASTMONEY_DATA_DIR` |

`run_xueqiu.sh` 额外识别 `XUEQIU_DATA_DIR`（优先级高于配置文件）。
各 wrapper 脚本都会自算脚本目录（不依赖调用时的 cwd），日志写入
`[paths] log_dir`（`/data/logs`，随数据卷持久化）。

容器内还需保证 `PYTHONPATH` 含各爬虫目录（`docker-compose.yml` 已设）：

```
PYTHONPATH=/root/apps/eastmoney:/root/apps
```

> 注：各脚本自身已做 `sys.path` 引导（把 `apps/` 加入路径），
> 所以脱离 `PYTHONPATH` 直接 `python apps/<mod>/<script>.py` 也能 import `config`。

## 📊 数据流向

```
apps/xueqiu_api/  → /data/xueqiu_data/
apps/eastmoney/   → /data/analyst_data/
apps/iptv/        → /data/iptv/
apps/news/        → /data/news/
```

（本机开发时 `/data` 映射为 `<项目根>/run`）

## ⏰ 定时任务

容器内 `/etc/cron.d/myjobs`（源文件 `configs/cron.d/myjobs`）：

```
0 */8 * * *  root  cd /root/apps/news       && /bin/bash run.sh            >> /data/logs/cron/news.log 2>&1
0 23 * * *   root  cd /root/apps/iptv       && /usr/bin/python3 download_m3u.py >> /data/logs/cron/iptv.log 2>&1
10 23 * * *  root  cd /root/apps/xueqiu_api && /bin/bash run_xueqiu.sh     >> /data/logs/cron/xueqiu.log 2>&1
20 23 * * *  root  cd /root/apps/eastmoney  && /bin/bash run_eastmoney.sh  >> /data/logs/cron/eastmoney.log 2>&1
```

> wrapper 脚本依赖**当前工作目录**（脚本内使用相对路径），crontab 必须先 `cd` 到对应目录。
